## 🌌 نبذة عن الأسطورة

**Omega-Bot** ليس مجرد كود، بل هو ثورة في عالم بوتات الواتساب. تم بناؤه ليكون **الأسرع** و **الأكثر تطوراً**، معتمداً على تقنيات متقدمة لضمان تجربة لا مثيل لها. سواء كنت تبحث عن إدارة متقدمة للمجموعات، أو تفاعل ذكي، أو حتى ألعاب تفاعلية، فإن **Omega-Bot** هو خيارك الأول.

## ⚙️ التثبيت والتشغيل

قم بتشغيل الأوامر التالية بالترتيب في التيرمينال (Termux أو VPS):

```bash
# 1. استنساخ المستودع
git clone https://github.com/NexusAi301/Omega-Bot.git

# 2. الدخول إلى المجلد
cd Omega-Bot

# 3. تثبيت الحزم
npm install

# 4. تشغيل البوت
npm start
